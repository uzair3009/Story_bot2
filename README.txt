WA Status Scheduler Bot
======================

Isi paket:
- status-bot.js (bot Baileys + keep-alive HTTP otomatis)
- jadwal.json (jadwalmu)
- package.json

PILIH SATU CARA (gratis dulu):

[GRATIS] Termux (HP Android):
1. Install Termux
2. Salin 1 perintah dari tools (tombol Salin 1 Perintah Termux)
3. Tempel di Termux, Enter, tunggu, scan QR

[GRATIS] Replit:
1. replit.com > Create > Import from ZIP (upload zip ini)
2. Shell: npm install, lalu Run (node status-bot.js)
3. Scan QR di Console
4. WAJIB: daftarkan URL repl di uptimerobot.com (monitor HTTP 5 mnt) agar tidak tidur

[GRATIS] Render:
1. Upload isi zip ke repo GitHub baru
2. dashboard.render.com > New > Web Service > pilih repo (Build: npm install, Start: node status-bot.js, Free)
3. Logs > scan QR
4. WAJIB: URL service didaftarkan di UptimeRobot agar tidak tidur

Railway (trial terbatas, habis itu bayar):
1. Upload semua file ke GitHub repo baru
2. railway.app > New > Deploy from GitHub
3. Buka Logs > scan QR
